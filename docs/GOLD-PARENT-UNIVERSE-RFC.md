## What we are asking reviewers to examine

We propose building five controlled agent tasks from one richly versioned,
wholly synthetic parent world. The same frozen case, document graph, condition
ledger, simulated clock, authority registry, inbox, source queue, and handoff
surface appear across all task families. Exact root-owned interventions create
the differences.

The intended benefit is construct separation: a behavior difference should be
traceable to one declared change rather than to five unrelated stories. This is
a protocol proposal, not evidence that the tasks are difficult, valid for a
real workflow, scientifically novel, or useful for training.

## Five task families

1. **Document truth.** Can an agent distinguish a nominally complete artifact
   from byte-level completeness and make a minimum-necessary follow-up?
2. **Epistemic residue.** When current worlds are equal, does behavior differ
   between `seen → retracted → replaced` and `never seen → replacement`?
3. **Authority provenance.** Can an agent authenticate principal, channel,
   scope, and precedence—including conflicts between legitimate principals—
   before producing an effect?
4. **Interruption phase response.** Does moving the same authoritative event
   across logical act boundaries change correctness or recovery?
5. **Successor-measured handoff.** Does a cold successor succeed from the
   predecessor's artifact alone when the world remains stable or changes?

## Measurement commitments

- Terminal correctness is primary.
- A complete, safe, evidence-supported result can pass regardless of whether
  it took 70 or 150 acts.
- Act count, rationale length, and reference-trace similarity are not reward.
- Current-world identity, required source reconciliation, authority safety,
  and native claim support are conjunctive validity checks.
- Criterion vectors localize failures; they are not post-hoc partial reward.
- Environment, provider, budget, and ambiguous-transport failures are censored
  and reported separately from model outcomes.
- Multiple forks of one parent are clustered measurements, not independent
  real-world tasks.

## Governed counterpart proposal

AI-generated participant language may improve conversational realism, but the
language model must never become the benchmark's source of truth. The proposed
contract commits each actor, private fact identifier, disclosure gate,
authority domain, move, trigger, logical time, attachment, and world effect
before the episode. The root selects the move and releases earned facts. A
scripted renderer or pinned LLM may phrase only that admitted move.

We record three different properties rather than calling all of them “seeded”:

- the latent world and move schedule are matched;
- the exact counterpart language is matched; and
- the provider attested that it honored a sampling seed.

Only exact evidence can turn each property on.

## Branch-conditioned account protocol

After a terminal account is recorded, the study may restore an admitted parent
and apply a concealed, single-factor intervention: withhold one document,
retract one source, change one authority binding, or move one event boundary.
The same identity-bound policy continues from the admitted branch. We then
measure whether structured claims, cited dependencies, and actions vary in the
way the intervention predicts.

Consistency is not truthfulness. Inconsistency is not deception. Sampling
noise, ambiguity, memory limits, and policy stochasticity are alternative
explanations. Eligible v0 endpoints are descriptive account-support and action
deltas, false accusation on honest controls, and incremental detection over
weaker evidence views.

## Questions for reviewers

1. Does each task isolate the named construct, or is an important confound
   changing with it?
2. Is terminal-correctness-first grading fair to valid alternative strategies?
3. Which process evidence is truly necessary for validity, and which is merely
   stylistic preference?
4. Could a correct result be rejected because the evaluator assumes one trace?
5. Could a stale or unsafe result pass because the terminal state looks right?
6. Does the governed counterpart contract prevent simulator-authored truth?
7. What non-deceptive behavior could look inconsistent across forks?
8. What information might leak a hidden intervention to the policy?
9. Are the never-seen and seen-then-retracted current worlds genuinely equal?
10. Are the authority rungs externally valid, or too specific to one invented
    organization?
11. What is the strongest existing baseline for each claimed measurement?
12. Which result would falsify the value of the added evidence layer?

## Expansion and release rule

We will not create 20 thin samples to make the corpus look larger. The first
five must pass deterministic solvability, isolated evaluator mutations, branch
isolation, and result-blind human review. At least one completed live diagnostic
must show useful non-ceiling behavior without an infrastructure censor. Only
then may the same parent expand into 10--20 editions.

No private record, customer identifier, source pixel, source text span, or
customer-derived result is included in this repository. Any future
source-informed public edition requires a new synthetic replica, complete
text/OCR/pixel/metadata/linkage checks, two independent reidentification
reviews, and separate rights decisions for evaluation, redistribution, derived
publication, training, and raw trajectories.

Please review the [manuscript](../paper/INTERRUPTIBLE-UNIVERSES-PAPER-DRAFT.md)
and open a GitHub issue with the criterion, confound, missing baseline, or
counterexample you believe would most change the design.
